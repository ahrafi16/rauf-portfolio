RUBAYED ALAM RAUF — PORTFOLIO

Files:
- index.html: page structure and content
- style.css: responsive styling, layout, and animations
- script.js: mobile navigation, reveal animations, scroll progress, and current year

HOW TO USE
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. Before publishing, replace hello@example.com in index.html with your real email address.
4. Review the text and update any details you want to personalize.
5. Photos and Google Fonts load from external services, so an internet connection is needed for those assets.

The extra soft-skill descriptions and future goals are suggested portfolio copy; edit them so they accurately reflect you.
